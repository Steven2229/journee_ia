# Journée IA – Fiches ateliers

Six fiches A5 (une par atelier) pour la journée du 1er décembre 2026 : `fiches-ateliers-A5.html`.
Ouvrir dans un navigateur, imprimer au format A5 sans marges. Données fictives uniquement.

- `index.html` : les six fiches, à imprimer en A5.
- `atelier-1.html` à `atelier-6.html` : une consigne par page, lisible sur téléphone (cible des QR codes).
- `qr-ilots.html` : planche A4 de six QR codes, un par îlot.

## Deuxième série : analyse de documents

- `analyse-1.html` : recours gracieux ; `analyse-2.html` : style d'infographie ; `analyse-3.html` : état hypothécaire (les autres suivront). Les documents de l'atelier 3 ne sont pas dans ce dépôt.
- `documents/` : documents anonymisés des exercices (jamais d'originaux ni de corrigés).
- `qr-analyses.html` : planche A4 des QR codes de cette série (générée par `outils/qr_analyses.py`).
